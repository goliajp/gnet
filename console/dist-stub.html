gnet SPA not built

This control-plane binary embeds the gnet console SPA from console/dist/, but that directory was empty at build time. The placeholder you are seeing was written by build.rs so the binary still compiled.

From the repo root:

cd console && bun install && bun run build

then rebuild this binary (cargo build --release -p gnet-console, -p gnet-discover, or -p gnet-relay-server) and the real SPA will replace this page.

The JSON API at /api/* is unaffected and already live.
